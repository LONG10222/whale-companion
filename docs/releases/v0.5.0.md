# Whale Companion v0.5.0

在 v0.4.1 的语音、引用与升级保护基础上，加入可恢复的自主作息和 B站资料阅读适配。

- 作息窗口、随机时刻和休息决定持久化；支持跨午夜、暂停与热更新。修复重启后旧“运行中”活动永久挡住后续计划的问题。
- 先筛简介，再有限深读字幕、热评、弹幕与可用抽样画面。可选复用本地转写和画面文字识别，逐条记录实际渠道与时间范围。
- 本机分享日记与内部活动本、带来源的“喜欢／少看”反馈；主动分享继续使用现有 QQ 队列和原有每日一次、未回复不追发限制。
- 新增评论、主人私信、指定直播间的倾听设置和回复草稿。默认关闭，新渠道均需审核；不猜私信收件人或直播间。
- 持久化请求预算、平台暂停与未知回执去重；慢媒体流不会因固定35秒租约过期而被另一个进程抢占。
- 保留 dsh-bili-whale 固定提交的 MIT 署名、许可证与移植说明。未分发其凭据、人格、媒体、接口文档或模型。

真实只读测试确认已有扫码登录有效，但媒体请求被平台拒绝后停止；本轮未发送 QQ 或 B站公开互动。抽帧／无字幕识别的真实账号验收未通过，不能称为完整观看或完全复刻。直播为有界历史轮询，高流量时可能漏消息。详细能力和差距见 [B站与自主生活说明](../BILIBILI_LIFE.md)。

## English

Adds persistent autonomous activity windows, bounded source-aware Bilibili reading, two local diary views, feedback and reviewed optional inbox replies on top of v0.4.1. Existing QQ permissions and unsolicited-message limits are retained. Shared request protection handles platform pauses, slow active requests, dead workers and uncertain writes.

This is a partial adaptation of dsh-bili-whale with its fixed-revision MIT notice retained. Live-room support uses bounded history polling, not real-time streaming. A real read confirmed the existing encrypted login but stopped on a platform media rejection; this release does not claim successful live frame/OCR/ASR acceptance or complete audiovisual viewing. No real QQ/Bilibili write was made during that probe. Private credentials, chats, databases, recordings, media and models are excluded from the source installer.
