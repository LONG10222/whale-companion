# Whale Companion v0.4.1

包含 [v0.4.0](v0.4.0.md) 的多音色、引用语音、短清唱、上下文与安全修复。

发行复核补正了中断升级的数据库边界：独立 QQ 客户端在应用升级时继续运行，它自己的 `data/qq-client` 数据库不参与应用回滚，也不作为“新聊天数据库变化”的阻断条件。鲸娅自己的记忆、联系人、权限和任务数据库仍严格校验，出现新数据就保留现场，不用旧备份覆盖。新增隔离回归证明 QQ 客户端数据保持原样。

Includes all [v0.4.0 features and fixes](v0.4.0.md). Corrects the interrupted-update boundary for the independently running QQ client: its `data/qq-client` databases are neither application rollback targets nor application-data guards. Whale Companion's own memory, contacts, permissions and task databases remain protected. A new isolated regression verifies that newer QQ-client data is preserved while application files recover.

音频样本仍只保存在操作者本机，自动识别不代替试听。源码发行包不含账号、密钥、QQ号、聊天、数据库、图片、音频或模型。This remains a source-only release; audio models are optional and recordings stay local.

未附实际引用却请求“念引用那句”时，会要求重新引用，不拿机器人最近的一句话代替。Requests naming an unavailable or unattached quote now ask for that reference instead of reading unrelated recent assistant text.
