# Whale Companion v0.4.0

本版完善语音的自然指令、增加独立聊天音色和短句自配清唱，并包含此前本地审查后未发布的安全与上下文修复。

## 功能与修复

- 保留默认角色参考声线，接通 Qwen3-TTS 的 Vivian、Serena、Dylan 聊天音色；按联系人和群会话保存选择。
- 分清引用朗读、上一句复述、指定文字与语音回答；成员群消息可在同群历史中核对；未取到引用不猜内容。引用 OCR 只使用绑定到引用的像素。
- 短句清唱由 DeepSeek 安排简单旋律和节奏，保留给定唱词与稳音连贯基线。聊天新音色不冒称已具备相同歌声。
- Qwen 仅裁剪多余首尾静音，保留句中停顿与播放速度；音频缓存按处理版本区分。
- 显式全性能音频模式；原有显存检查、单任务门控、缓存边界和任务后释放保留。
- 合入带来源记忆与人格接入、权威近期上下文、原生回执后提交历史、错误回退与完整回合期限修复。
- 合入文件只读快照、链接拒绝、动图有界解码、本地媒体鉴权、固定公网连接与查询含排队五分钟期限修复。
- 新版发起的升级记录持久文件事务；启动时可恢复未出现新数据/人工修改的中断文件切换。备份校验失败、数据库变化、旧版无事务记录时保留现场并禁止覆盖，不回滚新的聊天数据。
- 可选桌面启动链增加睡眠恢复入口，尊重暂停、联网前置检查与服务复用；不会主动唤醒电脑。

## 验证范围与限制

本地实际 RTX GPU 已生成三种新音色；短句“晚风轻轻吹”完成真实 DeepSeek 配谱、本地演唱、换声与无提示唱词识别。自动检查和测试不能代替使用者试听，也不能证明所有歌词、发音或情绪达到同样效果。首轮语气词测试出现“啦/了”的识别差异，保留这一检测限制；新生成文本仍需按实际试听判断。

升级恢复用独立目录中的真实子进程中断验证，未强制使用户电脑睡眠或断电。保留升级后产生的新数据优先于自动覆盖恢复。旧版 v0.3.0 发起的升级没有新版事务，不能追补不存在的日志。

发行包仅含源码、模板与校验清单；不含账号、Key、密码、QQ/群号、数据库、聊天、图片、录音、声音模型或参考素材。基本安装只需 QQ 与 DeepSeek Key；语音、清唱、绘图仍为需要单独配置的增强功能。

## English

This release adds distinct Qwen speaking presets, scoped voice selection, reliable quoted/previous-message readback and a separate answer-by-voice path. DeepSeek can arrange a simple short a cappella melody without changing supplied Mandarin lyrics. Stable pitch and lyric checks remain active; speaking presets are not misrepresented as singing voices.

It also includes the pending context, receipt-confirmed history, timeout, read-only snapshot, media decoding/authentication, pinned public-network transport and queued-query fixes. Explicit full-performance audio mode preserves actual-memory checks and worker cleanup.

Durable update file transactions permit guarded recovery after an interrupted switch. Changed databases, edited files, unverifiable backups and older unjournaled updates require inspection; new user data is never silently restored from an older snapshot. Resume-only desktop recovery respects paused state and the existing network/application startup gate.

Local GPU samples and one real DeepSeek-to-singing run were exercised. Automated checks do not certify human naturalness; listening remains necessary. Source-only packages exclude credentials, personal records, media and model weights. Optional local voice/singing runtimes require separate setup.
