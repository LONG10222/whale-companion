# Whale Companion v0.2.0

本版将现有 QQ 伙伴功能、独立安装向导、硬件配置和更新维护整合为可分发的 Windows 源码安装包。应用源码与私人运行数据分开发布。

## 安装与更新

- 下载下方 `WhaleCompanion-v0.2.0-windows-x64.zip`，完整解压后双击 `Install.cmd`。源码自动压缩包不等同于这个发行安装包。
- 安装器校验并下载自己的 Python、独立 QQ 与基础依赖；填写自己的 DeepSeek Key，登录专用机器人 QQ，再选择管理账号。
- 向导提供 20 类功能索引、依赖状态、三种硬件预设和九项资源参数。增强功能需要自己的账户、模型与许可素材。
- 新版定期在本机提醒，点击后升级；包含下载校验、任务等待、私人配置和 SQLite 备份、启动检查与失败回退。Python / QQ 主运行包变更仍需完整组件升级，不直接热替换 QQ。

## 集成内容

- QQ 号作为唯一身份键，单独管理联系人、普通/Plus/管理员权限；授权群按触发规则回应。
- 上下文、人格、记忆候选、表情含义、对话收尾、语音输入与历史成品找回；可选表情失败不覆盖文字回答。
- 大图片与群文件工作副本、视频抽帧及有界动图预览；语音、清唱与换声分阶段设置资源。
- 原图修图工作流 v2：规划、主体保护、对照审核、有界返修和实际候选选择。普通 Luna，Plus 主阶段为可用的 5.6 Terra，管理员主阶段最高 6.1 Sol/xhigh；全部普通速度。
- 受控工作对话、持久化查询额度、余额与用量日志；B站字幕阅读、分享、可取消的批次及分开授权的公开互动。公开默认不开作者的自动评论/投币设置。
- 只读资料快照、本机页面鉴权和动图处理预算等防护。

## 验证范围与已知限制

- 自动回归覆盖权限、身份、任务、文件边界、资源设置、更新成功/回退模拟和安装器；正式发布流程重新运行锁定环境中的回归与隐私检查。
- 本机已验证中文含空格目录首次环境准备、独立 QQ 未登录二维码生成、重复启动，以及设置页保存/刷新；未使用一台全新 Windows 虚拟机完成 QQ 登录全链路。
- 修图有真实生成/复核与既有候选回放验证，二者分别标记。Plus/普通 QQ 身份尚未各完成一次从收图到发图的真实整链；“大眼、睁眼”等定向五官修改不是当前已完成适配。
- 尚未在真实已登录安装上验证远端升级的完整切换；成功及失败回退有自动事务测试。不要把这项测试等同于真实 QQ 会话永不掉线。
- QQ 的扫码、手机确认、滑块和平台撤销登录仍可能需要本人处理。上游客户端和接口可能变化。
- 无微信、QQ 空间、主动加好友、桌宠或日常手机信息采集。字幕阅读不是完整观看视频。语音和图片自然度仍需实际验收。

不含账号、Key、密码、Cookie、联系人、聊天库、原图、模型权重、参考录音或下载表情包。来源与许可见 `ATTRIBUTIONS.md`，完整配置入口见 `docs/CONFIGURATION.md`。

## English

This Windows source-installer release integrates the QQ companion, a first-run wizard, 20 feature families, hardware presets, manual resource controls and owner-click updates. Extract the named Windows release archive and run `Install.cmd`; bring your own DeepSeek key and dedicated bot QQ. Optional Codex, speech/singing models and artwork remain separate.

The release includes identity-scoped memory and roles, contextual reactions, media input, bounded photo-edit orchestration, controlled work chats, usage records and independently authorized Bilibili reading/actions. All Codex work uses standard speed. Private runtime data is excluded.

Automated checks cover permissions, boundaries, update transactions and rollback. Fresh-PC QQ onboarding, every real QQ role's complete image-edit path, and a real logged-in remote-upgrade switch have not all been exercised. Replayed image validation is labelled separately from fresh generation. QQ may require human verification; optional models and aesthetic quality require local acceptance. Read the Chinese verification details above and the bilingual setup/architecture documentation before deploying.
