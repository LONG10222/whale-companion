# Security policy / 安全报告

Report a suspected permission bypass with a minimal sanitized reproducer. Never include active credentials, personal account numbers, a private database or a live exploit against another person's account. If a credential was exposed, revoke it with the provider before sharing a report.

This is a prototype with local-owner assumptions and optional unofficial QQ integration. Keep it on loopback, use a separate test account, maintain explicit recipient allowlists, and review changes before enabling new external actions. QR/captcha/password confirmation belongs to the account owner.

请优先使用仓库的私密安全报告入口（如已启用）；没有入口时先提交不含敏感细节的问题，申请联系渠道。不要在公开Issue粘贴密钥或完整聊天记录。
